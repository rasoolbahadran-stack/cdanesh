# مایگریشن‌های دیتابیس (MySQL/MariaDB)

اسکیمای کامل و وضعیت نهایی در `database/schema.sql` است و نصب‌کننده آن را یک‌بار اجرا می‌کند.
مایگریشن‌های افزایشی آینده در همین پوشه با نام `my00X_*.sql` قرار می‌گیرند؛ برنامهٔ Node آن‌ها را
از طریق جدولِ `_migrations` با قفل `GET_LOCK` به‌صورت اتمیک و idempotent اجرا می‌کند
(بخش مایگریشن درایور MySQL در `src/lib/db-mysql.ts`).

مایگریشن‌های قدیمی PostgreSQL (`src/lib/schema.ts` و بعدی) فقط برای سازگاری با استقرار
قبلی Neon/Vercel حفظ شده‌اند و روی هاست cPanel اجرا نمی‌شوند.
