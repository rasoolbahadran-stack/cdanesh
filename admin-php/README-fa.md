# پنل مدیریت PHP کافه دانش

این برنامه در پوشه مستقل `admin-php` قرار دارد و برای انتشار با Vercel Container آماده شده است. صفحات عمومی Astro و مسیرهای فعلی `/admin` در این مخزن تغییر نمی‌کنند.

## تنظیمات محیطی پروژه مستقل Vercel

- `DATABASE_URL`: رشته اتصال PostgreSQL همان Neon production.
- `ADMIN_USERNAME`: نام کاربری مدیر.
- `ADMIN_PASSWORD_HASH`: خروجی PHP از `password_hash('YOUR_PASSWORD', PASSWORD_DEFAULT)`.
- `ADMIN_SESSION_SECRET`: مقدار تصادفی طولانی برای امضای نشست و رمزگذاری کلید دستیار PHP.

در پروژه مستقل Vercel مقدار `Root Directory` باید `admin-php` باشد. دامنه پیشنهادی `admin.cdanesh.ir` است.

## ماژول‌های نسخه اول

مدیریت مقاله‌ها، صفحات، نمونه‌کارها، خدمات، دسته‌بندی‌ها، سؤالات متداول، تعرفه‌ها، دیدگاه‌ها و پیام‌ها؛ فرم ویرایش با فیلدهای سئو؛ گزارش فعالیت؛ جست‌وجوی درون فهرست‌ها؛ دستیار OpenRouter با کلید رمزگذاری‌شده و ذخیره‌سازی تنظیمات مستقل.

## نکات امنیتی

ورود فقط با متغیرهای محیطی انجام می‌شود. تمام عملیات تغییردهنده CSRF token می‌خواهند و نشست با کوکی HttpOnly و SameSite برقرار می‌شود. پنل هدر `noindex` دارد. به‌علت تفاوت کلید رمزگذاری پروژه مستقل، کلید OpenRouter نسخه PHP باید جداگانه وارد شود؛ مقدار تنظیمات دستیار Astro دست‌کاری نمی‌شود.
