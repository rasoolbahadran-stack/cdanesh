# سرویس PHP پنل مدیریت کافه دانش

این برنامه در سرویس مستقلی درون همان پروژه Vercel اجرا می‌شود و فقط مسیر `/admin` را دریافت می‌کند. سرویس Astro همچنان مسئول تمام مسیرهای عمومی سایت و APIهای فعلی است.

## استقرار

- نام سرویس Vercel: `php_admin`
- مسیر ریشه سرویس: `admin-php/`
- نشانی پنل: `https://cdanesh.ir/admin`
- پایگاه داده: اتصال Neon موجود پروژه و متغیرهای محیطی فعلی Vercel؛ هیچ رشته اتصال یا رمز جدیدی داخل مخزن ذخیره نمی‌شود.

## سازگاری دیتابیس

پیش از هر تغییر، برنامه ساختار جداول CMS کافه دانش را به‌صورت فقط‌خواندنی بررسی می‌کند. اگر جداول یا ستون‌های مورد انتظار موجود نباشند، برنامه متوقف می‌شود و هیچ تغییری اعمال نمی‌کند. تغییرات محدود PHP فقط افزایشی هستند (سطل زباله پنل، تلاش‌های ورود، و فراداده رسانه) و هیچ جدول یا محتوای اصلی Astro حذف یا بازنویسی نمی‌شود.

## ورود

ورود از اعتبارنامه‌های محیطی فعلی پروژه و هش رمز مدیر ذخیره‌شده در جدول کاربران استفاده می‌کند. نشست PHP نام و مسیر کوکی مجزایی دارد تا با نشست Astro تداخل نکند.
