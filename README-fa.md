# کافه دانش (Cafe Danesh) — پروژهٔ اصلی وب‌سایت و پنل مدیریت

این فایل، سورس کامل و قابل استقرار پروژهٔ کافه دانش است: وب‌سایت فارسی خدمات طراحی سایت، تولید محتوا و سئو + یک **سیستم مدیریت محتوای واقعی** که همهٔ بخش‌های سایت را بدون برنامه‌نویس مدیریت می‌کند.

- برند: کافه دانش (Cafe Danesh) — `https://cdanesh.ir/`
- فریم‌ورک: **Astro 5** (SSR) + PostgreSQL (**Neon**) روی **Vercel**
- حالت پیش‌نمایش محلی بدون دیتابیس هم پشتیبانی می‌شود (PGlite امبدد)

---

## ۱) این پروژه چیست؟

| بخش | توضیح |
|---|---|
| `src/pages` | صفحات عمومی سایت (خانه، خدمات، نمونه‌کارها، مجله، تماس، تعرفه‌ها و…) + API و پنل مدیریت |
| `src/pages/admin` | پنل مدیریت (داشبورد، مقالات، صفحات، خدمات، نمونه‌کارها، رسانه، پیام‌ها، دسته‌بندی، FAQ، تعرفه، نظرات، تنظیمات، امنیت) |
| `src/pages/api` | APIهای واقعی: احراز هویت، CRUD محتوا، آپلود رسانه، فرم تماس/مشاوره، خروجی CSV |
| `src/lib` | لایهٔ دیتابیس، احراز هویت، اعتبارسنجی، مایگریشن‌ها و دادهٔ اولیه |
| `server` | هندلرهای قدیمی سازگار با استقرار قبلی (در پروژهٔ جدید مستقیماً استفاده نمی‌شوند) |
| `public` | فونت‌ها، تصاویر، CSS و فایل‌های استاتیک |
| `scripts/build-static.mjs` | ساخت «نسخهٔ استاتیک نمایشی» (فایل ZIP دوم) |

## ۲) نصب و اجرای محلی

```bash
npm install          # نصب وابستگی‌ها
npm run dev          # اجرای محلی روی http://localhost:3000
```

بدون دیتابیس هم اجرا می‌شود؛ در این حالت از **PGlite** استفاده می‌شود و دادهٔ اولیه (خدمات، مقالات، تعرفه‌ها و…) به‌صورت خودکار ساخته می‌شود. هیچ دادهٔ واقعی حذف یا بازنویسی نمی‌شود.

## ۳) ورود به پنل مدیریت

- آدرس پنل: `/admin`
- رمز مدیر با متغیر محیطی `ADMIN_PASSWORD_HASH` (هش SHA-256 رمز) تعیین می‌شود:

```bash
node -e "console.log(require('crypto').createHash('sha256').update('رمز-شما').digest('hex'))"
```

- مقدار بالا را در `ADMIN_PASSWORD_HASH` قرار دهید. تغییر رمز از داخل پنل (تنظیمات › امنیت) هم ممکن است؛ در این حالت هش جدید در دیتابیس ذخیره و مقدم می‌شود و متغیر محیطی همچنان مرجع پشتیبان باقی می‌ماند.
- امنیت: کوکی نشست HttpOnly امضاشده، محدودسازی تلاش ناموفق ورود، کنترل دسترسی همهٔ APIهای مدیریتی در سمت سرور، ثبت فعالیت‌های مدیریتی.

## ۴) متغیرهای محیطی لازم

فایل `.env.example` را به `.env` کپی کنید:

| متغیر | ضروری؟ | توضیح |
|---|---|---|
| `DATABASE_URL` | برای دیتابیس واقعی (Neon) | اتصال PostgreSQL؛ خالی = پیش‌نمایش محلی PGlite |
| `ADMIN_USERNAME` | بله (پیش‌فرض `admin`) | نام کاربری مدیر |
| `ADMIN_PASSWORD_HASH` | بله | هش SHA-256 رمز مدیر |
| `ADMIN_SESSION_SECRET` | بله (تولید) | کلید امضای کوکی نشست |
| `BLOB_READ_WRITE_TOKEN` | برای آپلود در تولید | ذخیرهٔ تصاویر روی Vercel Blob؛ در محلی پوشهٔ `public/uploads` |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | اختیاری | اطلاع‌رسانی پیام‌های فرم |

هیچ رمز یا توکنی داخل سورس وجود ندارد.

## ۵) Build و Deploy (Vercel)

```bash
npm run build        # بیلد SSR (خروجی dist/)
npm run start        # اجرای بیلد با Node (تست محلی خروجی)
npm run build:static # ساخت نسخهٔ استاتیک نمایشی → پوشهٔ Cafe-Danesh-Static/
```

- روی Vercel: پروژه را متصل کنید؛ آداپتور به‌صورت خودکار Vercel انتخاب می‌شود (`VERCEL=1`).
- متغیرهای محیطی بخش ۴ را در تنظیمات Vercel وارد کنید.
- اتصال Neon: فقط کافی است `DATABASE_URL` معتبر `postgresql://` باشد؛ مایگریشن‌ها در اولین درخواست به‌صورت idempotent و **بدون حذف داده** اعمال می‌شوند.
- تصاویر: اگر `BLOB_READ_WRITE_TOKEN` ست باشد روی Vercel Blob ذخیره می‌شوند؛ آدرس تصاویر قبلی نمی‌شکند.

## ۶) نسخهٔ استاتیک نمایشی چیست؟

`npm run build:static` پوشهٔ `Cafe-Danesh-Static/` را می‌سازد: همهٔ صفحات عمومی به‌صورت HTML خالص در **یک پوشهٔ مسطح** با مسیرهای نسبی (`assets/css/style.css`، `assets/js/main.js`، `assets/img`، `assets/fonts`) که روی هر هاست ساده — و حتی باز کردن مستقیم فایل — درست نمایش داده می‌شود.

⚠ نسخهٔ استاتیک فقط برای **مشاهدهٔ ظاهر** است: فرم‌ها ارسال نمی‌شوند، پنل مدیریت و API ندارد و تغییرات محتوا فقط در نسخهٔ Astro اعتبارسنجی و ذخیره می‌شود.

## ۷) تفاوت نسخهٔ Astro و Static

| | نسخهٔ Astro (این فایل) | نسخهٔ Static (ZIP دوم) |
|---|---|---|
| هدف | سایت واقعی + CMS کامل | مشاهدهٔ ظاهر صفحات |
| دیتابیس | Neon / PGlite واقعی | ندارد |
| پنل مدیریت | کامل و عملیاتی | ندارد |
| فرم‌ها | ذخیرهٔ واقعی در دیتابیس | پیام «نسخهٔ نمایشی» |
| استقرار | Vercel + Node | هر هاست سادهٔ HTML |

## ۸) قابلیت‌های CMS در یک نگاه

- **داشبورد:** آمار مقالات (منتشرشده/پیش‌نویس/زمان‌بندی‌شده)، صفحات، خدمات، نمونه‌کارها، پیام‌ها، وضعیت دیتابیس و ذخیره‌سازی، آخرین فعالیت‌ها، میانبرها.
- **مقالات:** ویرایشگر فارسی RTL (تیتر، فهرست، تصویر با Alt، لینک، نقل‌قول، جدول)، پیش‌نویس/انتشار/**زمان‌بندی انتشار خودکار**، پیش‌نمایش پیش‌نویس، ذخیرهٔ خودکار، جست‌وجو/فیلتر/مرتب‌سازی، کپی و حذف گروهی، دسته‌بندی و برچسب.
- **سئوی هر محتوا:** عنوان و توضیح متا، Canonical، OG (عنوان/توضیح/تصویر)، Noindex، چک‌لیست راهنمای سئو، Schema.org، sitemap و robots.
- **رسانه:** آپلود واقعی (Blob/محلی)، پیش‌نمایش، ویرایش Alt، کپی آدرس، جست‌وجو/مرتب‌سازی، حذف با هشدارِ «در محتوا استفاده شده».
- **پیام‌ها:** ستارهٔ مهم، یادداشت داخلی، وضعیت (جدید/خوانده‌شده/پاسخ‌داده/بایگانی)، فیلتر و خروجی CSV.
- **خدمات، صفحات، نمونه‌کارها (با گالری تصاویر)، تعرفه‌ها، FAQ (با اتصال به خدمت)، نظرات، دسته‌بندی‌ها و تنظیمات کامل سایت** از پنل.
